NOBELY CAREERS CONNECT — VERCEL DEPLOYMENT

1. This ZIP contains the entire static site at the root. Upload the extracted folder to a GitHub repository, then import the repository into Vercel as an Other / static website project. Leave Build Command blank and Output Directory at the project root. Alternatively deploy this directory via Vercel CLI.
2. Forms on Contact, Candidates, and Employers send to nobley.infoconnector@gmail.com using FormSubmit.co, including resume attachment on Candidates. Vercel does not run PHP, so the prior send-message.php handler has been removed.
3. IMPORTANT: The first submission triggers a verification email from FormSubmit to nobley.infoconnector@gmail.com. Click the activation link to enable delivery. Test all forms after activation and check spam folders. Until activation, messages will not be delivered normally.
4. FormSubmit is a third-party processing service. Candidate and employer submissions, including resumes, are sent to FormSubmit first, then emailed to your inbox. Review the provider's data handling terms and ensure your privacy policy accurately discloses this before accepting personal data.
5. Resume attachment limit on website: 5 MB, PDF/DOC/DOCX. Server-side restrictions, email delivery, and spam filtering are controlled by FormSubmit.
6. Contact inbox: nobley.infoconnector@gmail.com. This website does not need a PHP server, SMTP credentials, or Vercel environment variables.
7. Job listings: do not publish invented positions or imply an employer relationship without verification.
